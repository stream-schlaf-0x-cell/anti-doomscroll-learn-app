# Atmen Codebase Remote Access (iPhone & Mobile Safari)

This directory provides direct mobile-friendly links and exports for inspecting, reading, or downloading the full Atmen codebase on iPhone, iPad, or any mobile browser.

---

## 1. Direct iPhone Codebase Downloads

### 📦 Complete Repository as ZIP (1 Tap to iOS Files App)
- **URL**: `https://github.com/stream-schlaf-0x-cell/anti-doomscroll-learn-app/archive/refs/heads/main.zip`
- **How to use on iPhone**:
  1. Tap the link above in Safari.
  2. iOS prompts: *"Möchten Sie „anti-doomscroll-learn-app-main.zip“ laden?"* -> Tap **Laden** (Download).
  3. Open the **Dateien (Files)** app on your iPhone -> Go to **Downloads**.
  4. Tap `anti-doomscroll-learn-app-main.zip` once: iOS natively decompresses it into a complete, browseable folder with all 230+ files!
